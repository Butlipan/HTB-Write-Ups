This repository contains write-ups for Hack The Box (HTB) machines, primarily for educational purposes. It includes step-by-step guides on enumeration, exploitation, and post-exploitation techniques

## ⚠️ Disclaimer:
All content is meant for learning and practicing in controlled, legal environments only. Do not use these techniques on systems without explicit permission

## 📚 Structure:

Each machine has its own folder containing:<br>
- **README.md or write-up document**
- **Screenshots, notes, and commands used**

Additional notes on Active Directory, privilege escalation, and enumeration techniques are included where relevant.
